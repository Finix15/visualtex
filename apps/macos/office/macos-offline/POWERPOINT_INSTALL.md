# Register VisualTeX.ppam in PowerPoint

VisualTeX installs the add-in at a stable path. PowerPoint requires a one-time manual registration; later VisualTeX updates overwrite the same file, so registration remains valid.

1. In VisualTeX, open **Settings → macOS Office integration**, then select **Show VisualTeX.ppam in Finder**.
2. Open Microsoft PowerPoint.
3. Select **Tools → PowerPoint Add-ins**.
4. Select the add button and choose:

   `~/Library/Group Containers/UBF8T346G9.Office/VisualTeX/OfficeAddins/VisualTeX.ppam`

5. Ensure **VisualTeX** is selected, then close the dialog.
6. Quit and reopen PowerPoint. The VisualTeX ribbon should appear.
7. Return to VisualTeX settings and refresh the status.

## Hướng dẫn tiếng Việt

VisualTeX cài phần bổ trợ vào một đường dẫn cố định. PowerPoint yêu cầu đăng ký thủ công một lần; các bản cập nhật sau sẽ ghi đè đúng tệp này nên không phải đăng ký lại.

1. Trong VisualTeX, mở **Cài đặt → Tích hợp Office trên macOS**, rồi chọn **Hiển thị VisualTeX.ppam trong Finder**.
2. Mở Microsoft PowerPoint.
3. Chọn **Tools → PowerPoint Add-ins**.
4. Nhấn nút thêm và chọn tệp tại đường dẫn nêu trên.
5. Bảo đảm **VisualTeX** được chọn, rồi đóng hộp thoại.
6. Thoát và mở lại PowerPoint. Dải băng VisualTeX sẽ xuất hiện.
7. Quay lại phần cài đặt VisualTeX và làm mới trạng thái.

## Repair / Sửa chữa

Use **Repair add-ins / Sửa chữa phần bổ trợ** in VisualTeX settings to reinstall the files and supporting scripts. Existing formulas in documents are not removed.
